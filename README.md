<h5>— Built using HTML,CSS,JAVASCRIPT,PHP,SQL and C++.</h5>

<p>✅. The Primary goal of this Project was to enhance Student Safety by Providing Real-time Location Tracking, Which could be Beneficial for Parents and Educational institutions.</p>
<p>✅. Utilized HTML, CSS and JavaScript for a user-friendly and responsive interface.</p>
<p>✅. Implemented PHP & C++ for backend logic, data processing, and user interactions.</p>
<p>✅. Managed the SQL database for efficient data storage and retrieval.</p>
<p>✅. We propose the Design of a smart sensor Network based on RFID Communication Technologies.</p>
<p>✅. Collaborated with a team, conducted testing, and provided ongoing updates to enhance system reliability and reduce costs.</p>
